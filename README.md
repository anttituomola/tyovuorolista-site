# tyovuorolista.fi website

Public marketing and content site for **[tyovuorolista.fi](https://www.tyovuorolista.fi/)**, a Finnish roster-planning SaaS for small and medium-sized businesses.

The production application is maintained in a private repository. This repository contains the public website: product pages, pricing, feature documentation, customer stories and practical articles about shift planning, working-time rules and collective agreements.

## Product context

I founded and develop tyovuorolista.fi based on experience from both hospitality operations and software development. The product is designed around a deliberately narrow promise: a small business should be able to start planning and publishing shifts without a sales process, implementation project or employee app rollout.

The website supports that product strategy through:

- Clear self-service pricing and signup paths
- Product and feature landing pages
- Finnish-language SEO content
- A low-JavaScript, performance-focused implementation
- Reusable content and layout components
- Automated sitemap generation and structured metadata

## Stack

- Astro 6
- React 19 for interactive components
- TypeScript
- AWS SES
- Vercel
- Node’s built-in test runner

## Local development

```bash
npm install
npm run dev
```

Run the test suite with:

```bash
npm test
```
